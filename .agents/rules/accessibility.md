# Accessibility Rules

## Semantics

- Utiliser les bonnes balises HTML avant toute abstraction.
- Structurer chaque page avec une hiérarchie de titres cohérente.
- Prévoir un texte alternatif pertinent pour les images utiles.

## Interaction

- Tous les contrôles doivent être accessibles au clavier.
- Les états de focus doivent être visibles.
- Les éléments cliquables doivent avoir une taille tactile correcte.

## Readability

- Garantir un contraste suffisant.
- Éviter les blocs de texte trop larges ou trop denses.
- Utiliser des libellés explicites pour les CTA, liens et formulaires.

## Motion

- Respecter `prefers-reduced-motion` pour les animations.
- Les animations ne doivent jamais bloquer l'accès au contenu.
